HARDWARE-TO-CLOUD PIPELINE

How The Alpha Squared System Works

From the patient's bedside or wearable device to caregiver emergency dispatch in under two seconds.

STAGE 01

Edge Sensor Sensing

ESP32 micro-controller queries bio-sensors (Pulse/SpO2, Temp, IMU Accelerometer, GPS) at 1-2 Hz intervals.

STAGE 02

On-Device Validation

Firmware validates noise bounds, computes jerk vectors for falls, and bundles telemetry with hardware timestamp.

STAGE 03

Firebase Realtime Sync

Payloads are transmitted over Wi-Fi / HTTPS directly to Firebase Realtime Database with sub-second event propagation.

STAGE 04

Telemetry & Alerts

Browser dashboard updates live without reload. Severe anomalies trigger automated caregiver email and SOS maps dispatch.
